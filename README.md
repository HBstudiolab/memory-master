# 암기 마스터

문제 이미지를 보고 **정답 위치를 직접 누르거나 활로 쏴서 맞히는** 암기용 웹앱입니다.
PC와 휴대폰 브라우저에서 동작하며, GitHub Pages에 올리면 어디서나 같은 주소로 쓸 수 있습니다.

- 정답은 번호를 입력하는 대신 **이미지 안의 정답 영역**으로 판정합니다.
- 맞힌 문제는 완료, 틀린 문제는 뒤로 보내 다시 출제합니다.
- 활쏘기 조준, 연속 정답 불화살(피버), 고스트 페이스메이커 같은 게임 요소가 들어 있습니다.

---

## 1. 빠른 시작 (Windows)

1. 프로젝트 폴더의 **`실행.bat`** 을 더블클릭합니다.
2. 로컬 서버가 켜지고 브라우저에서 `http://localhost:8000` 이 자동으로 열립니다. 8000번 포트를 이미 쓰고 있으면 8001~8020 중 빈 번호를 씁니다.
3. 서버 창을 닫으면 종료됩니다.

> `index.html` 을 직접 더블클릭해서(`file://`) 열면 브라우저 보안 때문에 문제 데이터(`regions.json`)를 읽지 못합니다.
> 반드시 `실행.bat` 으로 열거나 GitHub Pages 주소로 접속하세요.

Python이나 별도 프로그램은 필요 없습니다(Windows PowerShell만 사용).

---

## 2. 문제 추가하기

문제 목록과 정답은 **`datasets/default/regions.json` 한 파일**로 관리합니다.
정답 영역이 지정된 이미지 하나가 곧 문제 하나입니다.

1. 문제 이미지(PNG 권장)를 **`datasets/default/images/`** 에 넣습니다. 하위 폴더도 됩니다.
2. `실행.bat` 을 실행하고 **`http://localhost:8000/region-editor.html`** (영역 편집기)을 엽니다.
   새로 넣은 이미지가 목록에 바로 나타납니다.
3. 이미지마다 영역을 지정합니다.
   - **정답 영역** (단축키 `1`): 정답 보기 위치를 드래그해서 사각형으로 지정합니다.
   - **해설 영역** (단축키 `2`): 이미지 안에 해설이 같이 있으면 그 부분을 위아래로 드래그합니다(선택 사항).
4. **💾 저장** (`Ctrl+S`) 을 누르면 `regions.json` 에 바로 저장됩니다. 이전 파일은 `regions.json.bak` 으로 백업됩니다.
5. GitHub Desktop에서 **Commit → Push origin** 하면 웹사이트에 반영됩니다. **이미지 파일도 같이 커밋해야** 사이트에서 보입니다.

### 영역 편집기 조작

| 동작 | 방법 |
|---|---|
| 영역 그리기 | 드래그 (기존 영역을 대체) |
| 영역 추가 (정답이 여러 곳) | `Shift` + 드래그 |
| 영역 삭제 | 영역 클릭 후 `Delete` |
| 문제 이동 | `←` / `→` |
| 정답 / 해설 모드 | `1` / `2` |
| 저장 | `Ctrl+S` |

### 이미지 관련 팁

- **파일 이름이 곧 문제 제목**으로 표시됩니다. 예: `2025-1회-13번문제.png` → "2025-1회-13번문제"
- 파일 이름에 정답 번호나 `h`(해설)를 붙일 필요는 **없습니다**(예전 방식).
- 좌표는 이미지 크기 대비 비율(0~1)로 저장됩니다. 그래서 **같은 범위를 더 크게 캡처해서 같은 이름으로 덮어쓰면** 영역을 다시 지정할 필요가 없습니다.
- 글자가 또렷하게 보이려면 PDF나 화면을 **200~300% 확대한 상태에서 캡처**해 가로 600~900px 이상으로 저장하세요. 작은 이미지를 앱에서 키우면 흐려집니다.
- 이미지 파일 이름을 바꾸면 영역 연결이 끊어지므로 편집기에서 다시 지정하세요.
- 이미지를 지워도 `regions.json` 에 좌표가 남을 수 있는데, 앱이 실제로 없는 이미지는 자동으로 빼고 출제합니다.

## 3. 학습 화면 사용법

| 동작 | 방법 |
|---|---|
| 답하기 | 문제 이미지에서 정답 위치를 누르기 |
| 활로 쏘기 | 오른쪽 🏹 버튼을 **누른 채 드래그**해서 조준 → 손을 떼면 발사 |
| 크게 보기 | 이미지 오른쪽 위 **🔍 확대** |
| 정답·해설 보기 | 정답을 바로 확인(오답으로 기록되고, 나중에 다시 출제) |
| 나중에 풀기 | 이 문제를 뒤로 미루기(기록 없음) |
| 다음 문제 | 해설이 나오면 오른쪽에 뜨는 **→ 다음** 버튼, 또는 화면 안의 `다음 문제` 버튼 |

- 답하면 정답 영역이 초록색으로 표시되고, 해설 영역이 있는 문제는 이미지가 펼쳐지며 해설이 나타납니다.
- 이미지는 **원본 가로의 1.5배**로 보여주되, 문제 칸 너비보다 커지면 칸 너비에 맞춥니다(`IMAGE_SCALE`).
- 하단 **학습 설정**에서 이번 학습 문제 수(전체/10/20/50/100)를 고르고 `새 학습 시작`, `처음부터` 를 할 수 있습니다.
- 학습 기록은 **현재 브라우저**(localStorage)에 저장되어 창을 닫았다 열어도 이어집니다. 다른 기기와는 동기화되지 않습니다.

### 활쏘기 조준

- 버튼을 누르고 있으면 1인칭 스코프 시점이 되고, 활을 당기며 조금씩 줌인됩니다. PC에서는 마우스 휠로 줌(×1~×2)을 조절합니다.
- 드래그하면 십자선 아래로 문제가 움직입니다. 손을 떼면 줌이 풀린 뒤 화살이 날아가 **화살촉 끝이 십자선 중앙**에 꽂히고, 그 지점을 누른 것과 똑같이 채점됩니다.
- 너무 짧게 누르거나 `Esc` 를 누르면 발사하지 않습니다. 이미지 밖을 쏘면 채점하지 않습니다.

## 4. 게임 요소

### 정답 / 오답 연출
- **정답:** 맞힌 지점으로 카메라가 3번 연속 줌인하며 번쩍이고, 정답 테두리 잔상이 겹겹이 퍼지며 "정답!" 도장과 차임이 울립니다.
- **오답:** 문제 이미지 전체가 유리창처럼 금 갔다가 와장창 깨져 떨어지고, 화면이 크게 흔들리며 ✗ 가 찍힙니다.

### 불화살 (피버)
- **4문제 연속**으로 맞히면 배너가 뜨고, 다음 문제부터 불화살 모드가 됩니다(콤보가 끊길 때까지 유지).
- 화살이 불타며 날아가고 명중하면 **CRITICAL!** 연출이 나옵니다.
- 오답이나 정답·해설 보기를 하면 콤보가 0으로 돌아갑니다.

### 고스트 페이스메이커 (화면 맨 위)
러닝 페이스처럼 **1문제당 몇 초**로 표시합니다.

예: `1'29" /문제 · 목표 0'35" · 문제당 54초 느림 · 54초 뒤처짐`

| 항목 | 뜻 |
|---|---|
| 🏃 나 | 맞힌 문제 수만큼 전진 |
| 👻 라이벌 | 목표 페이스(1문제당 35초)로 쉬지 않고 달림 |
| 내 페이스 | (학습 시간 + 벌점) ÷ 맞힌 문제 수. 목표보다 빠르면 초록, 느리면 빨강 |
| 문제당 N초 느림/빠름 | 내 페이스와 목표 페이스의 차이 |
| N초 앞섬/뒤처짐 | 지금까지 쌓인 총 시간 차이. 뒤처지면 빨간 경고등, 앞서면 초록 |
| 벌점 | 오답·정답 보기 1번마다 **+20초** |

학습 시간이 멈추면(탭을 벗어나는 등) 라이벌도 멈춥니다.

## 6. 폴더 구성

```
index.html            학습 화면
region-editor.html    영역 편집기 (정답·해설 영역 지정)
app.js                문제 불러오기·채점·진행·이미지 표시
archery.js            활쏘기 조준·발사 연출·효과음
fx.js                 정답/오답 연출, 불화살, 고스트 페이스메이커
style.css             화면 스타일
실행.bat              로컬 서버 실행 (tools/serve.ps1)
tools/serve.ps1       로컬 웹 서버 + 편집기 저장·이미지 목록 기능
datasets/
  subjects.json       추가 문제 세트 목록 (기본 세트만 쓰면 [] 그대로)
  default/
    images/           문제 이미지
    regions.json      문제 목록 겸 정답·해설 영역
```

### regions.json 형식

```json
{
  "version": 2,
  "regions":  { "images/2025-1회-01번문제.png": [ { "x": 0.52, "y": 0.46, "w": 0.18, "h": 0.07 } ] },
  "explains": { "images/2025-1회-01번문제.png": [ { "x": 0, "y": 0.62, "w": 1, "h": 0.38 } ] }
}
```

- `x, y, w, h` 는 이미지 크기 대비 비율(0~1)입니다.
- `regions` 에 있는 이미지만 문제로 출제됩니다. `explains` 는 선택 사항입니다.

### 문제 세트 추가 (선택)

`datasets/subjects.json` 에 세트를 등록하면 하단 **문제 세트** 목록에 나타납니다. 그 세트 폴더 안에도 `regions.json` 과 `images/` 가 있어야 합니다.

```json
[ { "id": "power", "name": "전력공학", "path": "datasets/power/regions.json" } ]
```

영역 편집기의 자동 불러오기·서버 저장은 `datasets/default` 기준입니다. 다른 세트는 **📁 문제 세트 폴더 선택** 으로 열고, 저장한 파일을 그 폴더에 넣으세요.

## 7. GitHub Pages 배포

1. 저장소 **Settings → Pages → Build and deployment → Deploy from a branch** 에서 `main` 브랜치와 `/ (root)` 를 선택합니다.
2. 몇 분 뒤 `https://사용자이름.github.io/memory-master/` 로 접속합니다. 휴대폰에서도 같은 주소를 쓰면 됩니다.
3. 이후에는 이미지·`regions.json` 을 Commit → Push 하면 자동으로 반영됩니다.

> 공개 저장소에 올린 파일은 누구나 볼 수 있습니다. 문제 이미지의 공개·배포 권한을 확인하세요.

## 8. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| "문제를 불러오지 못했습니다" | `index.html` 을 직접 열지 않았는지 확인하고, `실행.bat` 으로 여세요. |
| "정답 위치가 지정된 문제가 없습니다" | 영역 편집기에서 정답 영역을 지정하고 저장했는지 확인하세요. |
| 사이트에 새 문제가 안 보임 | 이미지와 `regions.json` 을 **둘 다** 커밋·푸시했는지 확인하세요. 브라우저 새로고침도 해 보세요. |
| 편집기에 새 이미지가 안 보임 | 편집기 페이지를 새로고침하세요. 그래도 안 되면 예전 버전 서버가 떠 있는 것이니 `실행.bat` 창을 닫고 다시 실행하세요. |
| 이미지 글자가 흐림 | 원본을 더 크게 캡처해 같은 이름으로 덮어쓰세요(2장의 이미지 관련 팁 참고). |
| 학습 진행이 처음부터 시작됨 | 문제 목록이 바뀌면(이미지 추가·삭제) 이전 진행 기록과 맞지 않아 새로 시작합니다. |

## 9. 더 이상 쓰지 않는 파일

예전 방식(파일 이름 끝 정답 번호 + `h` 해설 파일)에 쓰던 파일들입니다. 지금 앱은 읽지 않으므로 지워도 됩니다.

- `datasets/default/questions.json`, `questions.json.bak`
- `tools/register_images.ps1`, `tools/convert_legacy.py`
