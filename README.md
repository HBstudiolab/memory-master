# 암기 마스터 — 1차 버전

PC 및 모바일 브라우저에서 사용하는 무료 정적 웹 암기 프로그램입니다.

## 1. 가장 쉬운 실행법

- `index.html` 파일을 더블클릭해서 브라우저에서 엽니다.
- 기본 예시 문제 3개를 풀 수 있습니다. (정답: 3, 2, 4)
- Chrome, Edge 등 최신 브라우저를 권장합니다.
- 실제 문제 세트를 `datasets/subjects.json`에 등록한 경우에는 **로컬 서버나 GitHub Pages**에서 열어야 해당 JSON이 읽힙니다. (`file://`에서는 브라우저 보안 때문에 외부 JSON 로딩이 차단될 수 있습니다.)

### 로컬 서버 실행 (선택)

Python이 설치되어 있다면 프로젝트 최상위 폴더에서 아래 명령을 실행한 후 `http://localhost:8000`에 접속하세요.

```
python -m http.server 8000
```

## 2. 기존 이미지 문제 파일 일괄 가져오기

기존 파일명 규칙:

- `국토계획법4.jpg` : 정답 4인 문제
- `국토계획법4h.jpg` : 그 문제의 해설

Windows에서 Python 3가 설치되어 있다면 프로젝트 폴더에서 아래 명령을 실행합니다.

```
python tools/convert_legacy.py "C:\Users\사용자\Desktop\암기자료" "나의암기자료"
```

- `암기자료` 아래 하위 폴더도 변환합니다.
- **확장자가 `.png`나 `.jpeg`여도 지원합니다.**
- 정답은 확장자 바로 앞 **마지막 숫자 한 자리**(0~9)로 해석합니다.
- `h`가 붙은 해설은 자동 연결합니다.
- 이미지 원본은 수정하지 않고 새 세트에 복사합니다.
- 변환이 끝나면 `datasets/subjects.json`에 자동으로 세트가 추가됩니다.
- 변환 후 반드시 몇 문제를 직접 풀어 정답과 해설 연결을 검증하세요.
- 파일 이름 끝이 숫자가 아닌 문제, 해설이 없는 문제 등은 로그에서 확인할 수 있습니다.

## 3. GitHub Pages 배포

1. GitHub에서 **공개(public)** 저장소를 하나 생성합니다. 예: `memory-master`.
2. 압축을 푼 폴더 속 파일과 폴더를 **저장소 최상위**에 업로드합니다. (`index.html`이 루트에 있어야 합니다.)
3. 저장소의 **Settings → Pages → Build and deployment → Deploy from a branch**에서 `main` 브랜치와 `/ (root)`를 선택하고 저장합니다.
4. 배포가 완료되면 `https://사용자이름.github.io/memory-master/`로 접속할 수 있습니다.
5. 휴대폰에서도 같은 주소로 접속하세요.

## 4. 동작 및 주의사항

- 문제는 무작위로 출제되며 맞힌 문제는 완료, 틀린 문제는 뒤로 보내 재출제합니다.
- 해설만 보면 오답으로 기록하고 뒤에 다시 나옵니다.
- 첫 시도 정답률은 문제별 최초 시도만 반영합니다.
- 중단 후 다시 열면 같은 브라우저의 `localStorage`에서 학습 상태를 복구합니다.
- PC와 휴대폰 사이 학습 상태 자동 동기화는 아직 없습니다.
- GitHub Pages에 올린 파일은 **공개적으로 접근 가능**합니다. 올릴 자료의 공개 및 배포 권한을 확인하세요.
- 정적 사이트이므로 브라우저에서 서버 파일을 직접 수정하거나 업로드하여 저장하지는 못합니다.
- 샘플 데이터는 기능 시험용이며 실제 시험 문제는 아닙니다.

## 5. 이후 추가 가능한 기능

텍스트 빈칸, 오답노트, 과목/단원 필터, 학습 이력 통계, PWA 홈 화면 설치, 기기 간 동기화 등.


## v1.1 화면 배치 변경

- 상단 제목 바로 옆에 `다음 문제` 버튼을 배치했습니다. 학습 중에는 문제를 뒤로 미루고, 해설 확인 후에는 다음 문제로 이동합니다.
- 문제 화면과 답안 입력 영역을 최상단으로 이동했습니다.
- 문제 세트, 이번 학습 문제 수, 새 학습 시작, 학습 현황, 처음부터 버튼을 화면 하단으로 이동했습니다.


## v1.2 화면 배치
- 제목 오른쪽에 남은 문제/완료/첫 시도 정답률/학습 시간을 작게 배치했습니다.
- 화면 순서는 문제 → (정답 확인 후) 해설 및 다음 문제 버튼 → 답안 입력 → 하단 학습 설정입니다.
- 상단의 다음 문제 버튼을 제거했습니다. 다음 문제 버튼은 해설이 나타난 후에만 보입니다.

## v1.3 — 정답 결과에 따른 다음 문제 버튼 위치

- **정답:** 문제 이미지 아래, 해설 위에 `다음 문제` 버튼이 나타납니다. 해설을 읽지 않고 바로 진행할 수 있습니다.
- **오답 / 정답·해설 보기:** 해설 이미지 아래, 답안 입력창 위에 `다음 문제` 버튼이 나타납니다.
- 답안을 제출하기 전에는 두 버튼 모두 숨겨지고, 다음 문제로 넘어가면 다시 숨겨집니다.
